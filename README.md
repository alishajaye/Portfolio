## Kurzbeschreibung
Das Portfolio zeigt meine Skills anhand von konkreten Projekten auf. Für einen schnellen Überblick habe ich die Projekte nach Kategorien gegliedert (die man auch filtern kann): Audio, Film, Journalismus, Marketing & Kommunikation und Events. Das Portfolio möchte ich hauptsächlich für Bewerbungen nutzen, deshalb habe ich noch meinen Werdegang und bisherige Arbeitserfahrung aufgelistet, sowie meinen Lebenslauf. Da das Portfolio auch mich als Person widerspiegeln soll, habe ich einige persönliche Fun Facts integriert und Bilder gewählt, die meine Skills, aber auch meine Interessen zeigen. 

Das Design für das Portfolio habe ich selbst mit Figma entworfen und anschliessend als eigenes WordPress-Theme umgesetzt. Dafür habe ich im WordPress-Backend wiederverwendbare Module erstellt, damit Seiten individuell zusammengesetzt werden können, ohne dass der Code dafür angepasst werden muss.

### Learnings
<ul>
    <li>Ich habe verstanden, was ein modularer Aufbau ist, wie dieser funktioniert und wieso es sich lohnt. Mit den Modulbaukästen lassen sich Seiten ganz einfach individuell zusammenbauen und das Design bleibt kohärent. Was auch super ist: Wenn ich in einem Modulbaukasten eine Änderung vornehme, wird das überall angepasst. Ich muss die Änderung nicht an jedem Ort manuell vornehmen. </li>
    <li>KI als Helfer wenn man ein Problem nicht lösen kann: Ich hatte ein Paar Mal ein Problem und konnte nicht herausfinden an was es liegt. Zum Beispiel hat es meine Schriftarten nicht übernommen. Mit Hilfe von Claude habe ich dann an verschiedenen Orten nachgeschaut, z.B. in den Entwicklertools beim Network-Tab oder Console. So konnte ich die tatsächliche Ursache finden, anstatt blind Lösungen auszutesten. </li>
    <li>Eine Änderung, die lokal funktioniert, ist erst sichtbar, wenn sie auf dem Server liegt. (Das war auch das Problem mit den Schriftarten, sie waren nicht auf dem Server.)</li>
    <li>Installierung von verschiedenen Plugins auf WordPress und was sie für einen Nutzen haben (Yoast SEO, Updraft Plus)</li>
</ul>

### Schwierigkeiten
<ul>
    <li>Schriftarten wurden im Browser nicht angezeigt -> Schriftdateien lagen nur lokal, nicht auf dem Server.</li>
    <li>Videos, die ich im WordPress eingefügt habe, erschienen im Browser nur als Rohtext -> eigene Ausgabefunktion.</li>
    <li>Zwei Videos, die ich hochladen wollte, waren zu gross für den Upload (Limit 300 MB) -> Videos als «nicht gelistet» auf YouTube hochgeladen und im WordPress eingebettet.</li>
    <li>Header war auf kleinen Bildschirmen (Handy) zu breit und man musste scrollen, um den ganzen lesen zu können -> Hamburger-Menü ergänzt</li>
</ul>
